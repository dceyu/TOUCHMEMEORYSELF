# CENTOPIA Mapping Studio v1.9.0

## 1.9.0：漩涡、边缘保护与全屏性能

CH2 改为向中心吸引的漩涡函数。粒子特效增加边缘权重，最外层粒子不受 CH3 收缩和 CH4 镇定等事件位移的影响。常态粒子亮度可单独调整，事件亮度在基础值上叠加。每个 CH 可单独设置缓进缓出时间，切换时新旧状态重叠混合。全屏模式下停止隐藏的控制预览渲染，并避免每帧重建 UV 几何与网格数据。

## 1.8.0：七个情绪状态、灵敏度与可调工作区

CH1–CH7 固定为怀疑、探索、欲望、自信、冲突、虚无、接纳。全部作用于同一批现有粒子，触发后保持当前状态；可在默认 15 秒或每项独立延迟后自动进入下一状态，最后回到常态。CH8 为光芒消散结束接口。增加 UV 素材取景框、1080p 预览、可拖动面板比例，以及 1 MΩ / 4.7 MΩ / 10 MΩ / 自定义触摸灵敏度。详见 [粒子事件说明](PARTICLE-EVENTS.md) 与 [触摸接线说明](TOUCH-SETUP.md)。

## Arduino 终端与跨电脑迁移（1.5.0）

顶部 **Arduino** 打开双语可视化终端。每一行是「传感器 → 防抖条件 → 单次效果」，可选择效果、持续时间、反向输入、阈值、通道启用及总接管开关。高电平保持时仅触发一次，稳定释放后重新待命。常态素材与力场继续播放。

1. 选择接线：原有 Uno + 4067（默认），或开关直连 Uno D3–D10（闭合接 GND）。Final 均为 D2 接 GND。
2. 选择 USB 端口，点击「验证程序」可离线编译；首次使用点击「写入 Uno 并连接」，确认后替换板上原程序。上传后自动连接；以后只需连接。改变接线方案后需重新上传。
3. Arduino 源码由接线选择自动生成，可在终端展开查看，随项目和导出包保存。此版本不运行任意用户脚本。内置官方 Arduino CLI、AVR 编译器和上传工具，无需 Arduino IDE；实际硬件可能需要对应 USB 串口驱动。
4. 保存仍使用 `.centopia-map`。终端「导出设置与素材」建立独立 `CENTOPIA-*` 文件夹，包含 `settings.centopia-settings`、`centopia.ino` 和 `media`。复制整个文件夹到新电脑，再点「导入设置 / 项目」打开设置文件。它恢复常态、Cue、节点、UV、时间线、语言、Arduino 接线和防抖参数；USB 端口和显示器需重新选择。

新终端用于 Uno；软件已经完成两种固件的实际编译和跨目录设置恢复测试，实物传感器接线及写入仍需在装置上验收。

Windows 桌面 Mapping 软件：本地图片/视频进入 WebGL2 效果链，通过 Arduino Uno + CD74HC4067 的 8 路连续输入控制视觉，并输出到单台 4K 投影设备。

## 当前能力

- CH1–CH7 各自触发一个可保持的情绪状态；CH8 结束。自动序列和每项延迟可独立控制。
- 画面由固定容量 GPU 粒子重新构成：投影约 23 万粒子、控制预览约 13 万粒子。
- 七个状态通过径向力、螺旋力、中心空洞、随机力、下落、回归、亮度和常态力场影响重构现有粒子。
- 独立常态粒子系统：所有粒子受同一个连续力场管理，可控制潮汐幅度、速率、全局随机力、方向、移动范围和轨迹长度。
- GPU 帧反馈产生发光纤维、连续流线和可缓慢消散的运动轨迹。
- JPG / PNG / WEBP / MP4(H.264) / WebM 素材与双播放器噪声溶解切换。
- 8 路连续输入的校准、平滑、阈值、迟滞、Attack / Release。
- 独立 Global Final 输入：效果缓慢归零，释放 500ms 后自动回到待机。
- 四点 UV 校正、亮度、黑场、显示器选择和独立无边框投影窗口。
- `.centopia-map` 项目文件、相对素材路径、缺失素材重新定位。
- 素材库支持删除项目引用，不会删除磁盘原文件。
- 素材时间线支持排序、逐项时长、循环播放和双播放器溶解衔接。
- 时间线可切换为条件推进模式：仅由 NEXT 按钮或指定 CH 的新触发切换到下一轨道。
- 节点连线控制可全局开启或关闭，并可双击单条连线切换 ON/OFF；默认不干扰 8 路一次性 Cue。
- UV 支持基础四点和 3×3 / 5×5 内部网格模式、素材取景框，并可进入全屏校正。
- 控制窗口可切换 ECO、标准、高质量、1080p 预览；投影输出仍保持独立高质量渲染。
- 左侧、预览区和右侧参数区可拖动改变比例，布局随项目保存。
- 投影窗口关闭后主预览会自动重建 GPU 显示，也可使用“刷新显示”手动恢复。
- 中英文界面可一键切换，语言选择会随项目保存。
- 量子点覆盖整个输出画面；导入素材后图片或视频会持续映射到点阵并受统一引力场影响，Cue 只负责叠加一次性形变。没有素材输入时点阵保持黑色。
- 常态力场、引力、移动范围、轨迹以及量子点尺寸和显色增益均保存到 `.centopia-map` 项目文件。
- 1.4.1 恢复素材的常态连续点阵播放，Cue 不再控制素材显隐。
- 1.4.0 增加双语界面、黑色无素材量子点渲染和图片载入自动重试。
- 1.3.1 修复 3×3 UV 网格 uniform 数量不足导致渲染循环停止、导入素材后黑屏的问题。
- 虚拟 Arduino 滑杆、FPS/质量监视和投影渲染自动降级。

## 开发与构建

```powershell
pnpm install
pnpm dev
pnpm test
pnpm build
pnpm package:win
```

打包结果位于 `dist-installer`。

安装包使用固定应用标识；安装新版本时会识别并替换上一版本，不需要手动删除。卸载或升级不会主动删除用户项目与素材。

## Arduino

上传 `arduino/sensor_stream.ino`：

- CD74HC4067 `SIG → A0`
- `S0–S3 → D4–D7`
- 8 路传感器 → `C0–C7`
- Final 开关 → `D2` 到 GND
- USB 串口 → 115200 baud / 40Hz

协议：

```json
{"version":1,"seq":1842,"channels":[0.12,0.45,0,0.81,0.24,0.6,0.32,0.09],"final":0}
```

## 素材说明

Chromium 不直接支持 MTS。软件会明确列出不兼容文件；请先转为 MP4/H.264 或 WebM。大型 4K 项目建议使用同帧率、短 GOP 的硬件解码友好素材，并在目标电脑上完成两小时压力测试。

旧版 `app.js`、`style.css` 和 `folder.css` 是早期 Canvas 原型参考，不再由桌面应用入口加载。

## 原始网页版

原始 Canvas 粒子版本已独立恢复到 `web/index.html`，避免与 Electron/Vite 桌面入口冲突。在项目目录双击 `启动原始网页版.cmd`，浏览器会打开 `http://localhost:8080/web/`。运行期间请保持命令窗口开启；关闭窗口即停止本地网页服务器。
